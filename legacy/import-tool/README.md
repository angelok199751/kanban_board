# Инструмент импорта из Google Таблицы (не используется)

Остался от раннего черновика, где планировалось перенести данные из старой таблицы.
По новому ТЗ (раздел 2) **данные не импортируются**: доски, колонки и свойства создаются в приложении с нуля.

Скрипт и шаблон написаны под старую схему БД (`profiles`, `board_properties`, `board_views` и др.), которой в проекте больше нет, поэтому **запускать их нельзя**. Файлы сохранены как справочный материал.
